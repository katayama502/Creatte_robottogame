# クリエット・コードバトル

クリエット君と なかまたちが、**プログラムカード**を ならべて 中央のボスに立ちむかう、**2〜6人用の 戦略カードゲーム**です。
島根県益田市の こどもプログラミング教室「クリエット」の キャラクターを使っています。

- 手札・ボスの予告・山札から出るつぎのカードまで、**ぜんぶ公開**。だれに見られても大丈夫なので、1台のタブレットやPCを みんなで回して遊べます（教室のプロジェクター投影にも向いています）。
- ボスに **いちばん多くダメージを与えた人の勝ち**。
- 1ラウンド目は 1番の人から、2ラウンド目は **ぎゃく順**（最後に動いた人が もう一度 先に動く）。行ったり来たりの順番です。
- プレイヤーが 1人動くたびに、ボスが公開カードどおりに **動いて、攻撃範囲を変えて** 攻撃してきます。

## 遊びながら身につく プログラミングの考え方

| カード | 考え方 | 内容 |
|---|---|---|
| まえへ・むきを変える・こうげき・ビーム | **順次**（じゅんばん） | 上から順に実行される。並べ方で結果が変わる |
| くりかえす 2 | **くり返し** | つぎのカードを2回。少ないカードで遠くへ |
| もし ボスが前 なら こうげき ／ もし あぶない なら にげる | **条件分岐** | その時の状況で動きを変える |
| 関数 もういちど | **関数** | 1・2行目を もう一度よび出して使い回す |
| デバッグ ／ バグ | **デバッグ** | バグはプログラムを止める。デバッグで直す |

ゲームの最後に、それぞれの考え方を何回使ったかの「学びのふりかえり」が出ます。

## ルール（かんたん版）

1ターンは 3ステップだけです。

1. **① カードを えらぶ**：手札（5まい）を タップして、プログラム枠（3つ・ロボットは4つ）に 並べる。盤面に「動いた後の位置（よそう）」と「そのあとのボスの攻撃範囲」が出るので、ためしながら考えられます。
2. **② 実行▶**：上から順に動く。目の前にボスがいれば こうげき（3ダメージ、ボスのせなかからなら +1）。こうげき・ビーム・くり返し などに それぞれエフェクトが出ます。使ったカードの分だけ、山札から **ランダムに** 新しいカードが 手札に入ります。
3. **③ ボスのばん（自動）**：公開されている「つぎのボスカード」どおりに ボスが動いて攻撃。範囲内のプレイヤーは HP がへり、1マスふきとぶ。技によっては 手札に バグ（最大2まい）が入る。

- **HP**：みんな HP5。0になると **ダウン**：点数（あたえたダメージ）が 2 へり、スタート地点で HP 全回復。デバッグカード・うさぎ治癒師で回復できる。
- **おわり**：ボスをたおす（とどめ +2）か、決めたラウンドがおわったら終了。ダメージがいちばん多い人の勝ち。同点ならダウンが少ない人 → のこりHPが多い人。

### 音（BGM・効果音）
- タイトル・バトル・いかりモードの3曲のBGMと、こうげき・ビーム・くり返し・バグ・ボスの技などの効果音があります。
- すべてブラウザの Web Audio で **その場で合成** しているので、音声ファイルは使っていません（著作権の心配なし・通信なし）。
- 右上のボタンで「BGM＋効果音 → 効果音だけ → 音なし」を切りかえられます（教室では「効果音だけ」もおすすめ）。ブラウザのきまりで、最初に画面をタップしたあとに鳴りはじめます。

### キャラクター（とくいわざ）
クリエット君（こうげき+1）／まほうつかい（2マス先までとどく）／ロボット（プログラム枠4つ）／きつねのコン（まえへ +1マス）／発明家ビーバー（くりかえす3回）／ふくろう賢者（手札を6まい持てる）／うさぎ治癒師（ターンのはじめに HP+1・バグを1まい消す）／かめ守護騎士（1ラウンドに1回ボスの攻撃をふせぐ）

### ボス
- **バグスライム**（かんたん）：まわり1マスをぴょんぴょん攻撃
- **時計ドラゴン**（ふつう）：いつも同じ順番で動く。パターン（くり返し）を見ぬけば よけられる
- **まおうドラゴン**（むずかしい）：いちばんダメージを与えた人をねらってくる
- HPが半分になると「いかりモード」になり、新しい技がふえます

## GitHub Pages で公開する

ビルド不要の静的サイトです（HTML / CSS / JavaScript のみ、外部ライブラリなし）。

1. このフォルダの中身を GitHub の新しいリポジトリ（例：`creatte-boss-battle`）に push します。
   ```bash
   git init && git add . && git commit -m "クリエット・コードバトル"
   git branch -M main
   git remote add origin https://github.com/＜あなたのアカウント＞/creatte-boss-battle.git
   git push -u origin main
   ```
2. GitHub のリポジトリで **Settings → Pages → Build and deployment → Source：Deploy from a branch**、Branch を **main / (root)** にして Save。
3. 1〜2分で `https://＜あなたのアカウント＞.github.io/creatte-boss-battle/` で遊べるようになります。

## 手元で動かす・テスト

```bash
npm start      # http://localhost:8080 で起動（file:// で直接ひらくと動きません）
npm test       # ルールの自動テスト（Node.js 20 以上）
node tools/sim.mjs   # バランス確認のシミュレーション
```

push するたびに GitHub Actions でテストが自動で動きます（`.github/workflows/test.yml`）。

## フォルダ構成

```
index.html          画面
css/style.css       見た目（スマホ・タブレット・PC・ダークモード対応）
js/engine.js        ルール（画面に依存しない。テスト対象）
js/ui.js            画面の動き・エフェクト
js/audio.js         BGM・効果音（Web Audio で合成）
assets/             キャラクター・ボス・背景の画像
test/               自動テスト
tools/sim.mjs       バランス確認
```

## 安全のための設計

- サーバーなし・通信なし（Content-Security-Policy で外部への接続・外部スクリプトを禁止）
- 画面はすべて `textContent` で組み立て、入力した名前がHTMLとして動かないようにしています（XSS対策）
- 名前は10文字まで。人数・キャラ・ボス・ラウンド数は ルール側でも検証
- 途中保存はそのブラウザの localStorage だけ。読みこむときに中身を検証し、おかしなデータは使いません
- 個人情報・パスワード・APIキーなどは 一切あつかいません
